# Slides by date

Slide decks built with [Marp](https://marp.app/), organised by date.

## Setup

```
make install
```

## Building

```sh
make 2026-04-28-marp.pdf       # PDF
make 2026-04-28-marp.html      # HTML
make 2026-04-28-marp.pptx      # PowerPoint

make all-pdf                    # all PDFs
```

Output goes to `output/`.

## Adding a deck

Create a folder named `YYYY-MM-DD-title/` containing a `slides.md`.
